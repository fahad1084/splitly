# Splitly

**Your Circle. Your Hisaab.**

Splitly is a Flutter expense-splitting app for groups — trips, flatmates, family, or friends. Add expenses, split them equally/custom/by percentage, track who owes who, chat with your group, and settle up — all in one place.

Built with **Flutter**, **Supabase** (Postgres, Auth, Storage, Realtime, Edge Functions), and **Riverpod** for state management. Push notifications run on **Firebase Cloud Messaging** via a custom Supabase Edge Function.

---

## ✨ Features

### Auth & Onboarding
- Email/password sign-up and sign-in
- Google Sign-In
- Forgot / reset password (deep-link based)
- Onboarding slides (first launch only)
- App Lock — 4-digit PIN + biometric unlock, auto re-locks on background
- In-app **Delete Account** (anonymizes profile, preserves shared expense history for other group members, disables login)

### Groups
- Create a group or join with an invite code
- Share invite code (copy or share sheet)
- Archive / leave group, remove members, promote/demote admins
- Group photo upload

### Expenses
- Add expense — split **equally**, **custom amounts**, or **by percentage**
- Receipt scanner (on-device OCR via Google ML Kit) to auto-fill the amount
- **Recurring expenses** (daily / weekly / monthly) — auto-generated by a scheduled Supabase function
- Full searchable/filterable expense history, including a **custom date-range** filter

### Balances & Settling Up
- **Pairwise debt calculation** — every debt shown is a direct relationship between two people (never rerouted through an uninvolved third member, unlike a "minimum transactions" algorithm)
- Privacy-first — you only ever see debts you're actually part of, not every debt in the group
- One-tap Settle Up; the other party's side clears automatically

### Chat
- Realtime group text chat
- Voice messages, photo attachments, reply-to-message
- @mentions with autocomplete
- Typing indicators, unread message badges per group

### Notifications
- Push notifications (Firebase Cloud Messaging, WhatsApp-style sender avatar as the large icon) for new messages, new expenses, settlements, and new members
- **Privacy-scoped**: expense/settlement notifications only reach people actually involved — not the whole group
- In-app notification history (bell icon) with a rich detail sheet per notification
- Per-category mute toggles (Profile → Notifications)

### Reports & Export
- Spending charts by category and by member, with time-period and custom date-range filters
- PDF / CSV export of a group's expenses
- WhatsApp-ready "Share Summary"

### Other
- Full English + Urdu localization
- Light / dark / system theme
- Avatar photo upload with in-app cropping (falls back to a colored initial when no photo is set)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (stable channel)
- A Supabase project
- A Firebase project (for FCM + Google Sign-In)
- Supabase CLI (for deploying the notifications Edge Function)

### 1. Clone & install
```bash
git clone <this-repo>
cd splitly
flutter pub get
```

### 2. Environment variables
Create a `.env` file in the project root (never committed — see `.gitignore`):
```
SUPABASE_URL=https://<your-project>.supabase.co
SUPABASE_ANON_KEY=<your-anon-key>
```

### 3. Firebase
- Run `flutterfire configure` to generate `lib/firebase_options.dart`
- Place `google-services.json` in `android/app/`
- Enable **Google Sign-In** in Firebase Authentication (or just Supabase's Google provider) and set the matching **Web Client ID** in `auth_controller.dart`

### 4. Database
Run the SQL migrations (in `supabase/migrations/` if present, or apply manually via the Supabase SQL Editor) to set up tables, RLS policies, and the notification/recurring-expense functions.

### 5. Edge Function (push notifications)
```bash
supabase login
supabase link --project-ref <your-project-ref>
supabase secrets set --env-file secrets.env   # FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, FIREBASE_PRIVATE_KEY, WEBHOOK_SECRET
supabase functions deploy send-push-notification --no-verify-jwt
```
Then set up **Database Webhooks** (Supabase Dashboard → Integrations → Database Webhooks) on `messages`, `expenses`, `settlements`, and `group_members` (INSERT), pointing to the deployed function URL with an `x-webhook-secret` header.

### 6. Run
```bash
flutter run
```
